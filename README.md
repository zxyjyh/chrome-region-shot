# Region Shot · 区域截图

一个 Chrome 扩展：在网页上拖拽框选一个矩形范围，自动截取该范围内的内容——**从选区顶部一直到页面底部**，保存为 PNG。

不需要手动滚动页面。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `chrome-region-shot`
4. 把扩展图标固定到工具栏（可选）

## 使用

1. 在任意普通网页上点击扩展图标，或按 `Alt+Shift+S`
2. 拖拽一个矩形，框住你要截取的范围：
   - 选区使用**文档坐标**，拖到视口上下边缘时会自动滚动，可以跨越多屏继续拖
   - 也可以用滚轮 / 触摸板自己滚动，选区框会跟着内容走，不会错位
   - 松手时框住多大就截多大，不会自动延伸到页面底部
3. 截图过程中，扩展图标角标显示分段进度（如 `1/3`），结束时显示 `OK`，失败显示 `!`
4. 选区阶段按 `Esc` 或点右键取消

> 选区阶段页面不会滚动，这是有意为之：选区坐标是相对当前视口的，一旦滚动就会错位。

## 工作原理

1. 注入全屏遮罩，用户拖出矩形选区；选区坐标是文档坐标（`clientY + scrollY`），所以滚动不会让选框错位
2. 拖到视口上下边缘时自动滚动，选区可以跨越多屏
3. 通过 `chrome.debugger` 调用 CDP：
   - `Page.getLayoutMetrics` 获取文档尺寸
   - `Page.captureScreenshot` + `captureBeyondViewport: true` + `clip`，按文档坐标精确截取选区矩形
4. 超过单次尺寸上限时自动分段截取，在 background 里用 `OffscreenCanvas` 拼接
5. 保存 PNG；`downloads.download` 失败时退回页面内 blob 下载

因为 `captureBeyondViewport` 能直接渲染视口外内容，所以**完全不需要滚动页面**，也就不存在「滚不动」「滚动距离对不上」「吸顶元素重复」这些问题。

## 权限说明

| 权限 | 用途 |
|---|---|
| `activeTab` | 只在你点击扩展时，临时获得当前标签页的访问权 |
| `scripting` | 注入框选界面 |
| `downloads` | 保存截图文件 |
| `debugger` | 调用 CDP 截取视口之外的页面内容。**截图期间浏览器顶部会短暂出现「正在调试此浏览器」的黄条**，结束后自动消失 |

## 已知限制

- 截图期间顶部会出现调试提示条
- 截取范围完全由选区决定，不再自动延伸到页面底部
- 最长约 30000 设备像素，超出部分会被截断
- 懒加载 / 虚拟列表：视口外尚未渲染的内容可能是空白
- 如果该标签页开着 DevTools，扩展无法附加调试器，会显示 `!`
- `chrome://` 开头的页面、Chrome 应用商店、其他扩展页面无法截图
- 水平方向只截取选区宽度，页面有横向滚动时会包含当前横向位置

## 可扩展方向

- 选区后可选「整页宽度」或「只截选区宽度」
- 截图完成后直接复制到剪贴板
- 加标注（箭头、文字、马赛克）
