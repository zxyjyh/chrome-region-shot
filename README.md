# Region Shot · 区域截图

一个 Chrome 扩展：在网页上框选任意起始位置和结束位置，截取这一块内容（可以跨越多屏），保存为 PNG。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `chrome-region-shot`
4. 把扩展图标固定到工具栏（可选）

## 使用（两段式，对触摸板友好）

1. 在任意普通网页上点击扩展图标，或按 `Alt+Shift+S`
2. **第一步：拖拽**确定起点和宽度（拖到视口上下边缘会自动滚动）
3. 松开鼠标后进入第二步：**两指滚动**到你想结束的位置，选区框会随滚动延伸
4. **点击页面任意位置**确认，开始截图
5. 截图过程中，扩展图标角标显示分段进度（如 `1/3`），结束时显示 `OK`，失败显示 `!`
6. 任意阶段按 `Esc` 或点右键取消

> 为什么分两步：Mac 触摸板上「按住拖拽」和「两指滚动」没法同时做，所以把定起点和定终点拆开，中间可以正常滚动。

## 工作原理

1. 注入全屏遮罩，用户拖出矩形选区；选区坐标是文档坐标（`clientY + scrollY`），滚动不会让选框错位
2. 第一步结束、第二步开始后，正常滚动页面，选区底部跟随鼠标在文档中的位置延伸
3. 点击确认后，通过 `chrome.debugger` 调用 CDP：
   - `Page.getLayoutMetrics` 获取文档尺寸
   - `Page.captureScreenshot` + `captureBeyondViewport: true` + `clip`，按文档坐标精确截取选区矩形
4. 超过单次尺寸上限时自动分段截取，在 background 里用 `OffscreenCanvas` 拼接
5. 保存 PNG；`downloads.download` 失败时退回页面内 blob 下载

因为 `captureBeyondViewport` 能直接渲染视口外内容，截图本身不需要滚动页面。

## 权限说明

| 权限 | 用途 |
|---|---|
| `activeTab` | 只在你点击扩展时，临时获得当前标签页的访问权 |
| `scripting` | 注入框选界面 |
| `downloads` | 保存截图文件 |
| `debugger` | 调用 CDP 截取视口之外的页面内容。**截图期间浏览器顶部会短暂出现「正在调试此浏览器」的黄条**，结束后自动消失 |

## 已知限制

- 截图期间顶部会出现调试提示条
- 截取范围由选区决定，不会自动延伸到页面底部
- 最长约 30000 设备像素，超出部分会被截断
- 懒加载 / 虚拟列表：视口外尚未渲染的内容可能是空白
- 如果该标签页开着 DevTools，扩展无法附加调试器，会显示 `!`
- `chrome://` 开头的页面、Chrome 应用商店、其他扩展页面无法截图
- 水平方向只截取选区宽度

## 可扩展方向

- 选区后可选「整页宽度」或「只截选区宽度」
- 截图完成后直接复制到剪贴板
- 加标注（箭头、文字、马赛克）
