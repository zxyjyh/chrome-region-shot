# Region Shot · 区域截图

一个 Chrome 扩展：在网页上拖拽框选任意矩形区域，**自动滚动并把该区域拼成一张长图**，保存为 PNG。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `chrome-region-shot`
4. 把扩展图标固定到工具栏（可选）

## 使用

1. 在任意普通网页上点击扩展图标，或按 `Alt+Shift+S`
2. 鼠标拖拽画出要截取的区域
3. 松开鼠标后，扩展会从当前位置开始逐屏向下滚动，自动拼接成长图
4. 完成后自动下载到浏览器默认下载目录，文件名形如 `region-20261117-153600.png`
5. 选区阶段按 `Esc` 或点右键取消

## 工作原理

1. 注入全屏遮罩，用户拖出矩形选区
2. 优先使用 `window` 滚动；只有页面本身不可滚时，才探测选区下方最近的可滚动元素
3. 循环：`captureVisibleTab` 截图 → 在 background 里用 `OffscreenCanvas` 裁剪选区 → 按滚动位移拼接 → 滚动一屏 → 等待渲染
4. 滚到底或达到上限后，导出图片并恢复页面原始滚动位置

截图数据全程在 background 内处理，不经过页面脚本，避免大图传输失败导致「只截一屏、页面不滚动」。每帧只保留底部「新滚动出来的部分」，因此拼接不会重复。

## 权限说明

| 权限 | 用途 |
|---|---|
| `activeTab` | 只在你点击扩展时，临时获得当前标签页的访问权 |
| `scripting` | 注入框选界面、滚动控制和拼接逻辑 |
| `downloads` | 保存截图文件 |

没有申请「读取所有网站数据」这类常驻权限，也不需要后台常驻访问任何页面。

## 已知限制

- 只能截取网页内容，**不能截浏览器窗口之外的桌面**
- **固定/吸顶元素会重复**：`position: fixed` / `sticky` 的导航栏、悬浮按钮在每一屏都会出现，拼接后会重复多次。目前未做自动隐藏
- 选区高度不能超过视口高度；只截**选区宽度**内的内容，不截选区外的部分
- 最长拼接高度约 16384 设备像素（受 canvas 上限约束），超出部分会被截断
- 最多截 80 屏
- 截图过程中页面会滚动，结束后会恢复原位置；如果页面有懒加载，滚动时会触发图片加载
- `chrome://` 开头的页面、Chrome 应用商店、其他扩展页面无法截图（Chrome 禁止注入脚本）
- iframe 内的内容会随主文档一起被截取，但无法单独精确框选 iframe

## 可扩展方向

- 自动隐藏选区内覆盖的 fixed/sticky 元素，消除重复
- 截图完成后直接复制到剪贴板
- 加标注（箭头、文字、马赛克）
- 框选后按元素自动吸附（用 `document.elementFromPoint` 找最近的块级元素）
